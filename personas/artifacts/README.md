# Artifacts

Working material from persona-based review runs: draft plans, reviewer output, transcribed source
evidence. Kept so the *derivation* behind a decision survives, not just the decision.

One subfolder per run, named `<subject>-<YYYYMMDD>`.

**Nothing here is authoritative.** These are superseded drafts and point-in-time critiques. The
decisions they led to live in the real planning documents; the retrospective on how the process
performed lives in [../findings/](../findings/). Read artifacts to answer *"why was it done this
way, and what was ruled out?"* — never to find out what the current design is.

Worth keeping because the alternative is losing the reasoning. A plan records what was decided; it
rarely records the option that was verified and rejected, or the arithmetic that killed a draft. The
second time someone proposes the rejected thing, this folder is the difference between re-running
the analysis and reading it.

Each run's subfolder carries its own README with the lineage and what to read first.
